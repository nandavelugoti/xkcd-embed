# Embeddable xkcd comic 

Easily embed a minimal looking xkcd comic any where you want.

> Privacy first: No tracking, no telemetery, pure memes.

## For example:

### Code:
```html
<iframe width="640px" height="600px" style="border:none;">
<!DOCTYPE html>
<html>
  <head>
    <script src="xkcd-embed.js"></script>
  </head>
  <body>
      <div id="xkcd-embed"></div>
  </body>
</html>
</iframe>
```

### Embed live view:

<iframe width="640px" height="600px" style="border:none;">
<script src="./xkcd-embed.js"></script>
