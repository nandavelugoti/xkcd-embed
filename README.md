# Embeddable xkcd Comic 

Easily embed a minimal looking xkcd comic any where you want.

> Privacy first: No explicit tracking or telemetery. Only memes.

# Embed Instructions

Step 1: Load `xkcd-embed.js` by adding this to your html head:

```html
<script src="https://raw.githack.com/nandavelugoti/xkcd-embed/refs/heads/main/xkcd-embed.js"></script>
```

Step 2: Use it anywhere you want in the html by:

```html
<div id="xkcd-embed"></div>
```
